# Производительность

Цель оболочки — быстрая публичная витрина (ориентир Lighthouse Performance ≥ 90 на десктопе для `/`), без тяжёлого маркетингового стека.

## Архитектура

- **Next.js App Router.** Страницы — React Server Components. HTML отдаётся сразу, без гидрации всего макета.
- **SSG.** Публичные маршруты не читают cookies, не вызывают динамические API и не ходят в БД. Сборка кладёт статику.
- **Клиентский JS точечно.** Формы, демо-сессия в шапке, фильтр каталога компаний, подсветка активного пункта меню. Публичная вёрстка и тексты — серверные. Мобильное меню — `<details>`.
- **Нет Framer Motion, нет UI-китов, нет аналитики.** Бандл не тащит motion/runtime и сторонние SDK.
- **Демо-сессия в localStorage**, не в cookie: сервер по-прежнему отдаёт статику гостевого HTML, кабинет дорисовывается на клиенте.

## Шрифты и CSS

- **Manrope** подключается через `next/font/google` с `display: "swap"` и подмножествами `latin` + `cyrillic`. Нет render-blocking `<link>` на fonts.googleapis.com.
- Токены цвета и радиусов — CSS-переменные в `app/globals.css`, в Tailwind через `@theme inline`.
- Иллюстрации — CSS-плейсхолдеры (`PlaceholderArt`), не тяжёлые растры и не чужие стоковые 3D.

## Сеть и JS

- `poweredByHeader: false`, gzip/compress включён в Next.
- Prefetch ссылок App Router по статическим маршрутам — штатный, без ручных SPA-фреймворков поверх.

## Что не делаем в этой версии

- Нет Prisma, auth, realtime, админ-API.
- Нет ленивой подгрузки больших галерей — галерей нет.
- Картинки банка / чужие иллюстрации не копируем и не грузим.

## Как проверять

```bash
npm run build
npm start
```

Дальше Lighthouse по `http://localhost:3000/` в режиме desktop, без расширений. Если метрика просядет, сначала смотреть чужой JS и шрифты в Network, а не добавлять новые клиентские острова.
