# Центр услуг

Маркетинговый сайт и оболочка B2B-платформы **«Центр услуг»** (недвижимость, стройка, генподряд, сделки с бизнесом). Город запуска — **Ульяновск**.

Репозиторий раньше содержал курсовую (расписание матчей). История git сохранена; текущая главная — этот сайт.

**Это не продукт Сбера** и не связан со СберБанком. Совпадают только привычные паттерны деловой оболочки (плашка-навигация, тёмная подложка, карточки). Свои цвет, шрифт Manrope и тексты.

## Стек

- Next.js App Router + TypeScript
- Tailwind CSS
- React Server Components, статическая генерация публичных страниц
- Manrope через `next/font/google` (кириллица + латиница)

Бэкенда, базы, авторизации и платежей нет. Кнопка «Войти» пока нерабочая. Форма заявки — клиентский компонент с `preventDefault`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
npm run lint
```

## Маршруты

| Путь | Содержание |
| --- | --- |
| `/` | Главная |
| `/feed` | Открытая лента |
| `/companies` | Витрина компаний |
| `/services` | Услуги |
| `/cases` | Типовые кейсы |
| `/certificates` | Описание справок (заказ — после входа) |
| `/about` | О центре |
| `/for-specialists` | Специалистам |
| `/request` | Заявка |

Гость видит компании, услуги и ленту. Чёрный список, статусы доверия, сообщения и кабинет справок — только после регистрации; на витрине их нет.
